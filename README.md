# Market — 1C Configuration

![1C:Enterprise 8.3](https://img.shields.io/badge/1C:Enterprise%208.3-3b3a36?style=flat-square) ![BSL](https://img.shields.io/badge/BSL-3b3a36?style=flat-square) ![Python generator](https://img.shields.io/badge/Python%20generator-3b3a36?style=flat-square) ![XML](https://img.shields.io/badge/XML-3b3a36?style=flat-square)


An internal management-accounting configuration for grocery stores, fully in Azerbaijani, for 1C:Enterprise 8.3.
The interesting part: **the configuration is generated by a Python script** — catalogs, documents, registers and forms are
described once and emitted as 1C XML, then loaded into a ready database.

## What a store gets

| Area | Features |
|---|---|
| **Cashier workplace** | Open shift, scan barcodes, **pack barcode adds the whole pack** (e.g. 10 units), hotkeys: F8 cash · F9 card · F10 credit · F11 mixed · F4 void |
| **Stock** | Goods receipt with expiry dates, opening balances, write-offs with reasons, minimum stock |
| **Money** | Cash desks, bank accounts (card payments), supplier debt, customer credit limits |
| **Roles** | Admin · Manager · Storekeeper · Cashier (cashier opens straight into the POS) |

## Design choices
- Technical names in ASCII (`MalQebulu`), user-facing names in full Azerbaijani (`Mal qəbulu`) — no encoding issues in code.
- Phase-based scope: core turnover first, then reporting and loyalty.
- Validation scripts check the generated XML before it is loaded.
